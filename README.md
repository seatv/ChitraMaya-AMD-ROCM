# ChitraMaya — AMD Radeon (ROCm) edition

> [!IMPORTANT]
> $${\color{red}\textsf{This repository is archived. ChitraMaya for AMD Radeon (ROCm) now ships from the main repository, and downloads are at}}$$
> ## **<https://get.chitramaya.org>**

Since **1.80.00** (October 2026) all three editions — NVIDIA, AMD Radeon and Intel Arc — are built from one source tree and released together:

- **Downloads** (every edition, every file with its SHA-256): <https://get.chitramaya.org> — the AMD Radeon (ROCm) installer is `ChitraMaya-rocm-install.exe`, a single file.
- **Source code, release notes and the issue tracker**: <https://github.com/seatv/ChitraMaya> (the same code is kept at <https://gitlab.com/seatv/chitramaya>).
- **User Guide**: <https://get.chitramaya.org/userguide.html> — section 14 covers the AMD Radeon (ROCm) edition; the Scaling Guide beside it has the measured speeds.

The release pages of this repository stay for the versions that were published here; they are superseded by 1.80.00 and will not receive updates. Please do not open issues here — this repository is read-only. Report at <https://github.com/seatv/ChitraMaya/issues> instead.

*ChitraMaya is AGPL-3.0. It takes no money; if it is useful to you, consider giving to Save the Children.*
